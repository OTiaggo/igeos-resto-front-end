# Domínio

## Vocabulário

| Termo | Significado |
| --- | --- |
| Restaurante | Unidade operacional considerada pelo produto IGEOS Resto; sem seleção ou cadastro aprovado neste componente. |
| Previsão | Estimativa de um valor futuro; sua apresentação na interface ainda depende de contrato aprovado. |
| Épico | Resultado de produto que reúne features relacionadas. |
| Feature | Capacidade de produto com resultado observável para um participante real. |
| História | Necessidade de um ator, resultado esperado e critérios de aceite verificáveis. |

## Conceitos, estados e invariantes

Não há entidades, regras de negócio, estados ou invariantes de produto aprovados
para implementação neste front-end. Os conceitos do componente irmão são contexto;
não se tornam contratos da interface apenas por existirem na API.
